# Cisco Packet Tracer Labs

A collection of networking labs built using Cisco Packet Tracer to practice networking fundamentals, network configuration, and troubleshooting.

## Topics Covered

- IPv4 addressing and subnetting
- VLAN configuration
- Inter-VLAN routing
- Static routing
- Router and switch configuration
- Network connectivity and troubleshooting

## Requirements

- Cisco Packet Tracer
- Basic understanding of IPv4 networking

## Labs

Each lab includes a .pkt file containing the network topology and configurations, along with a screenshot for quick reference.

## How to Use

1. Clone or download this repository.
2. Open the desired `.pkt` file using Cisco Packet Tracer.
3. Inspect the topology and device configurations.
4. Run connectivity tests and explore the configuration.

## Learning Goals

This repository documents my hands-on practice with networking, configuration, and troubleshooting.
